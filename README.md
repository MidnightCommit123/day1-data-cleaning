# Day 1 - Data Cleaning with Pandas & SQL

Cleaned a messy supermarket sales dataset and loaded it into a database.

## What I did
- Removed duplicate rows
- Fixed missing values
- Standardized text (e.g. "Nairobi " -> "Nairobi")
- Created a SQLite database with DB Browser
- Wrote SQL to create table and query data

## Tools
Python, Pandas, SQL, SQLite, Git

## Files
- `day1_cleaning.py` - cleaning script
- `sales_dirty.csv` - raw data
- `day1.db` - cleaned database
